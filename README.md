### Core Architecture & Focus

* **Cloud & Backend:** Deploying scalable architectures across **Oracle Cloud (OCI)**, **Microsoft Azure**, and **Zoho Catalyst**.
* **Agentic AI & Data:** Designing autonomous AI workflows, LLM orchestration, and **Vector Database** pipelines.
* **Mobile & Web:** Building native/hybrid **Android APKs** (Kotlin, Capacitor), iOS apps (Swift), and modern full-stack web platforms.
